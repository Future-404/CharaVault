## 1. 目标

将当前承担所有信息与操作的全屏详情弹窗，重设计为兼顾角色欣赏、设定阅读和局部编辑的“角色档案页”。

成功标准：

- 用户进入页面后 2 秒内能够识别角色、作者和主要分类。
- 用户最多通过两次标签点击找到任意主要字段。
- 用户看到目标字段后，通过一次操作进入该字段的编辑状态。
- 详情页满足 WCAG 2.2 AA：正文对比度至少 4.5:1，交互控件对比度至少 3:1。

## 2. 范围

本轮包含：

- 角色详情页的信息架构、首屏构图和滚动行为。
- 角色设定、开场与对话、世界书与高级三个内容分区。
- 字段级编辑的入口和基本交互原则。
- 空字段、长文本、图片异常和减少动态效果等状态。

本轮不包含：

- 具体 Compose 实现和数据库变更。
- 全局品牌色、字体或应用其他页面的重设计。
- 新增 Character Card V3 之外的业务字段。

## 3. 已确认设计决策

### DEC-001：页面定位

采用“沉浸与效率并重”的角色档案页：首屏强调角色视觉，向上滚动后进入结构化资料区。

### DEC-002：编辑模式

移除全局“编辑角色卡”按钮。页面保持阅读态，每个字段提供明确的就地编辑入口。

- 同一时间只编辑一个字段。
- 字段进入编辑态后提供“取消”和“保存”。
- 保存以字段为交互单位，但底层应一次性写回完整角色数据，不得在每次键入时写入 PNG。
- 存在未保存内容时离开编辑态，需要提示是否放弃修改。
- 名称、作者、分类、长文本和列表条目分别编辑。

### DEC-003：首屏视觉——双层舞台

采用双层图像构图：

- 背景使用同一张角色图的全屏放大、暗化和轻微模糊版本。
- 前景角色图保持主体尽量完整，不使用实体卡片边框。
- 前景图无厚重阴影，与背景通过亮度和渐变自然融合。
- 底部使用稳定的深色渐变承载名称、作者和分类。
- 顶部保留返回和更多操作；不放置全局编辑按钮。

```text
┌──────────────────────┐
│ ←                  ⋯ │
│                      │
│     沉浸式暗化背景      │
│       完整角色主体      │
│      无边框融入背景      │
│                      │
│      底部深色渐变        │
│ 艾莉娅                    ✎ │
│ @Luna ✎  #奇幻 #女性 +2 ⚙ │
│          ═           │
└──────────────────────┘
```

### DEC-004：首屏信息层级

采用“左对齐档案式”和“信息压缩式”的混合布局：

- 名称大字号左对齐，最多两行，并提供字段编辑入口。
- 作者和分类处于同一紧凑信息层。
- 默认显示最多两个分类，其余以 `+N` 表示。
- 点击 `+N` 查看完整分类；分类管理使用明确入口。
- 小屏宽度不足时允许分类换行，不通过缩小字号强行容纳。

### DEC-005：连续折叠滚动

首屏向内容区过渡时采用连续折叠：

- 上滑时图片逐渐缩小、变暗。
- 角色名称进入紧凑顶部栏。
- 内容分区导航吸附在顶部。
- 用户可以停在任意滚动位置，不做强制整屏吸附。
- 系统启用“减少动态效果”时，退化为无缩放的普通滚动与吸顶切换。

### DEC-006：三个独立内容标签页

第二屏使用三个独立标签页：

1. `角色设定`
2. `开场与对话`
3. `世界书与高级`

规则：

- 通过点击标签切换，不启用左右滑动切换。
- 每个标签页独立保存滚动位置。
- 标签使用文字，不用只有图标的导航。

### DEC-007：角色设定——编辑档案式

`角色设定`按“背景与描述、性格特征、对话场景”纵向排列：

- 不为每个字段套独立卡片。
- 使用标题、留白和细分隔线建立层级。
- 长文本默认显示约 6–8 行，并提供独立的“展开全文/收起”按钮。
- 每个字段标题旁提供编辑入口。
- 空字段使用轻量添加入口，不显示大型空容器。

### DEC-008：开场与对话——纵向对话稿

`开场与对话`按以下顺序展示：

1. 默认开场白。
2. 备选欢迎语列表。
3. 对话示例（仅在存在数据时展示）。

规则：

- 默认开场白优先展示。
- 备选欢迎语纵向编号，每条支持复制、编辑、排序和删除。
- 页面提供新增欢迎语入口。
- 对话示例为空时完全隐藏，不保留空状态或添加行。
- 添加对话示例的入口收进页面顶部的新增菜单。

### DEC-009：世界书沿用现有词条设计

`世界书与高级`不重做世界书词条本体，优先保留现有词条设计和当前编辑习惯。

- 先把现有世界书词条作为原子内容单元接入新详情页。
- 不在本轮重构词条列表样式、词条编辑模型和词条层级结构。
- 若后续需要调整，只做壳层承载与入口整合，不动词条内容组织方式。

### DEC-010：不保留独立高级设置按钮

主页面不单独暴露“高级设置”按钮。

- 频率低、风险高或暂时没有明确归属的操作，统一收进右上角“更多”菜单。
- 主内容区优先保持阅读和编辑路径清晰，不放置空壳入口。
- 如果后续高级项变得稳定，再考虑把它们以更明确的分组回到页面内。

### DEC-011：按字段类型进入对应编辑器

点击字段旁的编辑按钮后，直接进入该字段对应的编辑界面，不再先进入统一的全局编辑模式。

- 短字段优先原地编辑。
- 长文本、列表和多行内容进入全屏输入界面或等价的专用编辑界面。
- 同一时刻只允许一个字段处于编辑状态。
- 编辑态进入后仍保留取消和保存，避免误操作扩散到其他字段。

## 4. 当前页面结构

```text
角色详情页
├── 沉浸式首屏
│   ├── 返回 / 更多
│   ├── 双层角色图
│   └── 名称 / 作者 / 分类
└── 连续折叠后的内容区
    ├── 角色设定
    │   ├── 背景与描述
    │   ├── 性格特征
    │   └── 对话场景
    ├── 开场与对话
    │   ├── 默认开场白
    │   ├── 备选欢迎语
    │   └── 对话示例（有数据才显示）
    └── 世界书与高级
        ├── 现有世界书词条
        └── 高级设置
```

## 5. 可验证验收条件

### AC-DETAIL-001：首屏识别

Given 用户打开任意有效角色卡，When 首屏完成显示，Then 首屏同时可见角色图、名称、作者和至少两个分类或全部现有分类。

### AC-DETAIL-002：连续折叠

Given 用户位于首屏，When 用户向上滚动，Then 图片连续收起，角色名称和三个内容标签进入吸顶状态，且页面不发生强制整屏跳转。

### AC-DETAIL-003：字段级编辑

Given 用户正在阅读任意可编辑字段，When 用户点击该字段的编辑入口，Then 只有该字段进入编辑态，并显示取消和保存操作。

### AC-DETAIL-004：对话示例为空

Given 角色卡没有对话示例，When 用户打开“开场与对话”，Then 页面不显示对话示例标题、空容器或占位提示。

### AC-DETAIL-005：减少动态效果

Given 系统启用了减少动态效果，When 用户从首屏滚动到内容区，Then 页面不执行图片缩放或复杂视差动画，但保留普通滚动和吸顶导航。

## 6. 跨功能约束

| ID | 约束 |
|---|---|
| CFR-A11Y-001 | 正文文字与背景对比度必须达到 4.5:1。 |
| CFR-A11Y-002 | 交互控件视觉对比度必须达到 3:1。 |
| CFR-A11Y-003 | 主要触控目标应至少为 48dp。 |
| CFR-GESTURE-001 | 左右滑动不得作为内容标签切换方式。 |
| CFR-DATA-001 | 输入过程中不得按字符频繁写回物理 PNG 文件。 |
| CFR-STATE-001 | 标签页切换后必须保留各自的滚动位置。 |

## 7. 待讨论

- `世界书与高级`页面中高级设置的信息结构。
- 长文本字段进入编辑态后的高度、键盘和保存栏行为。
- 顶部“更多”菜单中的导出、删除及危险操作确认。
- 点击角色图是否进入纯净看图模式。
- 图片加载失败、无分类、异常 JSON 等边界状态。
- 平板和横屏布局。
